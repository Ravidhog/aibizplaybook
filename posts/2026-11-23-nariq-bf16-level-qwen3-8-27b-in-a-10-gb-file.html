NariQ: BF16-level Qwen3.8-27B in a 10 GB file

Published: 2026-11-23T13:42:38+00:00

We built NariQ: 3-bit-or-lower quantizations of Qwen3.8-27B that retain near-BF16 quality across agentic tasks, math, multilingual reasoning, and image understanding.

To our knowledge, this is the first 3-bit-or-lower quantization that retains BF16 lvl performance on long-horizon agentic tasks.

Benchmarks (BF16 / 3-bit / 2.5-bit / 2-bit):

- DeepSWE: 39.8 / 41.0 / 41.9 / 28.6

- Terminal-Bench 2.1: 62.6 / 63.8 / 60.2 / 52.4

- AIME 25+26: 97.7 / 98.3 / 96.5 / 86.0

- MSGM: 94.0 / 93.1 / 91.8 / 90.6

- RealWorldQA: 82.4 / 82.4 / 81.3 / 80.9

Decode speed is comparable to other quants on an RTX PRO 6000. Context-length results below

(3-bit / 2.5-bit / 2-bit / Unsloth UD-IQ3_XXS):

- 4K: 88.9 / 99.2 / 111.7 / 94.7

- 16K: 84.5 / 93.8 / 105.1 / 89.8

- 64K: 70.7 / 77.5 / 85.0 / 74.8

Running these currently require our llama.cpp fork: (https://github.com/nari-labs/nari-llama.cpp)

Feedback and questions welcome. We'd love to hear how these perform on your workloads.
